# mk61emu — емулятор «Електроніка МК-61»

[English](README.md) | Українська

Емулятор програмованого мікрокалькулятора **«Електроніка МК-61»**: стек X–Y–Z–T, 15 регістрів, 105 кроків програми, ті самі коди клавіш, що й на корпусі. Дві програми: консоль `mk61emu` і вікно на Qt 6 `mk61emu-gui`.

## Збірка з сирців

Потрібні CMake 3.25, компілятор із C++23 і, для вікна, Qt 6 (модуль Widgets).

```sh
cmake --preset gui
cmake --build --preset gui
ctest --preset gui
```

Після цього:

-   `./build/gui/apps/cli/mk61emu`
-   `./build/gui/apps/gui/mk61emu-gui`

Без Qt, тільки консоль і тести:

```sh
cmake --preset dev -DBUILD_GUI=OFF
cmake --build --preset dev
ctest --preset dev
```

Інші пресети в `CMakePresets.json`: `dev`, `release`, `sanitized`, `analyze`.

## Пакети

`scripts/package.sh` збирає `.deb` і `.tar.gz`. Якщо в системі є `linuxdeploy`, додасть ще AppImage. Qt з каталогу `~/Qt/<версія>/gcc_64` скрипт знаходить сам; інакше задайте `CMAKE_PREFIX_PATH`. Файли лягають у `dist/`. Текст для GitHub Release — у `packaging/GITHUB_RELEASE_v1.0.0.md`.

```bash
sudo apt install ./mk61emu_1.0.0_amd64.deb
```

Архів `mk61emu-1.0.0-Linux.tar.gz` розпаковується в каталог із `bin/`, `lib/` і `share/`. Запуск: `bin/mk61emu-gui` і `bin/mk61emu`. Qt уже лежить у `lib/`, системний пакет Qt не потрібен.

## Консоль

Без аргументів з’являється рядок `МК-61 [АВТ | PC=00]>`. Живого натискання клавіш немає: слова пишуть через пробіл і тиснуть Enter, тоді вони виконуються по черзі. Команди самої програми починаються з двокрапки. Що писати замість кожної клавіші — `:keys`, як користуватися — `:help`.

```text
2 В↑ 3 +
10 ^ 2 F ↔          # ^ це В↑: десятка лишається в Y, у X буде 2^10
:deg
30 F 7              # sin 30°, над 7 — sin
:p                  # список прикладів
:p 1
2026 В/О С/П        # Великдень 2026: у X місяць, у Y день
```

`:h` — команди, `:k` — схема клавіш, `:asm` — ввід програми (мнемоніки, мітки або таблиця 10×10), `:l` і `:g` — лістинг, `:s` — крок, `:r` — регістри, `:save` і `:load` — файл `.mk61`.

```sh
mk61emu --keys "2 В↑ 10 F ↔"
mk61emu --preset easter -x 2026 --run
mk61emu --preset quadratic --reg 1=1 --reg 2=-5 --reg 3=6 --run
```

Повний перелік прапорців — `mk61emu --help`.

## Вікно

Корпус повторює панель МК-61. Клік по клавіші спрацьовує одразу, так само як і клавіша комп’ютера (Enter — `В↑`, пробіл — `С/П`, F і K — префікси). Якщо курсор у тексті програми, літери йдуть у текст, а не на калькулятор. Наведення на клавішу показує, що вона робить. `F12` ховає бічну панель, `F10` робить крок, `F5` ганяє програму з паузою, `F9` ставить точку зупину.

Готові програми і свій текст — вкладка «Редактор програм». Довідка по самому калькулятору — вкладка «Інструкція МК-61». Кнопка **Про** біля рядка режиму на індикаторі відкриває версію, час збірки і ліцензію.

З клавіатури комп’ютера: цифри і `+ - * /` як на корпусі, Enter — `В↑`, Esc і Backspace — `Сх`, пробіл — `С/П`, Home — `В/О`.
